## 📂 Project Setup

Follow these steps to run Jenny Store locally.

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone this repository:

   ```bash
   git clone https://github.com/smartgrowth39/Jennystore.git
   ```

3. Move the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL from XAMPP Control Panel.
5. Open phpMyAdmin.
6. Create a database and import the project's `.sql` file.
7. Update the database connection settings in the project configuration file.
8. Open your browser and visit:

   ```text
   http://localhost/jenny_store/
   ```
